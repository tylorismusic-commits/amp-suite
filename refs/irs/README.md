# Reference IRs (not shipped)

Place manually downloaded TONE3000 reference WAVs here, one folder per amp:

```
refs/irs/chorus-clean/
refs/irs/chime/
refs/irs/crunch/
refs/irs/hot-rod/
refs/irs/block-120/
refs/irs/stealth/
refs/irs/recto/
```

These files are T3K-licensed and must not be committed. They are analysis
targets for `tools/ir_fit.py`; the generated IRs in `assets/irs/` are original
CC0 works.
